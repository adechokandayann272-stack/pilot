Assistant IA

Interrogez votre projet en langage naturel : tâches, échéances, agenda, commentaires et historique.

Confidentialité : l'application n'a pas de serveur IA. Quand vous envoyez une question, le fichier complet du projet (y compris noms, commentaires et suivi), la date affichée, les priorités épinglées et l'historique récent sont transmis directement au fournisseur choisi. Votre clé API est elle aussi envoyée directement à ce fournisseur ; n'utilisez qu'un service autorisé pour ces données. Si vous cochez « Mémoriser », la clé est conservée en clair dans le stockage local du navigateur.

Connecter un fournisseur d'IA

La connexion se fait avec votre propre clé API. Les appels partent directement du navigateur : le fournisseur doit autoriser les requêtes CORS depuis l'adresse où vous ouvrez l'application. Les fournisseurs proposant une API compatible OpenAI peuvent être configurés comme « Autre compatible ».

Synchronisation Notion

Publiez une copie lisible et complète du projet dans une page Notion dédiée.

Connexion sécurisée : le token Notion est envoyé uniquement au petit serveur local, puis conservé en mémoire côté serveur. Il n'est jamais écrit dans le fichier projet ni dans le stockage du navigateur. La page Notion créée est mise à jour à chaque synchronisation ; son contenu est remplacé par l'état actuel du projet.

Connecter l'API Notion

Pour protéger votre token, la synchronisation passe par un pont local. Lancez python3 notion_bridge.py, puis ouvrez l'application à l'adresse affichée par le serveur. Créez une intégration interne dans Notion et partagez avec elle la page de destination.

Comment préparer Notion ? ▾
  1. Dans Notion, créez une intégration interne et copiez son token.
  2. Créez une page qui servira de dossier de destination, puis partagez-la avec cette intégration.
  3. Lancez python3 notion_bridge.py dans le dossier de l'application et ouvrez http://127.0.0.1:8765.
  4. Collez le token et l'URL (ou l'ID) de la page, puis cliquez sur « Connecter ».

    Mode d'emploi ▾
    Démarrer : saisir son nom, puis « Ouvrir un projet existant » (le fichier .json du dossier partagé) ou « Créer un nouveau projet ». Edge ou Chrome enregistrent directement dans le fichier .json partagé ; avec Firefox, Safari ou un mobile, les données restent dans le navigateur et s'exportent en .json (boutons en bas de page).
    Tâches : « + Nouvelle tâche » pour ajouter ; cocher = terminée ; « Modifier » pour l'échéance, le rôle, le responsable, le statut ; « Annulé » la retire (rétablissable en bas de page).
    Toutes les tâches : la liste complète du projet, toutes échéances et tous statuts confondus, groupée par urgence ; recherche et filtres par statut, lot et responsable, tri par échéance, lot, responsable ou intitulé. Les tâches terminées et annulées sont repliées en bas de page.
    Actions de réunion : « Coller les actions d'une réunion » : copier la liste d'actions d'une note (Granola, Teams, mail), la coller, vérifier l'aperçu (responsable, échéance) puis créer les tâches en un clic.
    Agenda : « + Ajouter un événement » (réunion, atelier, butoir…). Les priorités tiennent compte des réunions du jour quand leur intitulé contient un module du projet.
    Partage : chaque collègue ouvre la même page et le même fichier depuis le dossier OneDrive/Teams synchronisé. Tout est signé du nom saisi. La page relit le fichier toutes les 15 secondes.
    Sauvegarde : « Exporter en Excel » produit une copie lisible du projet (tâches, commentaires, agenda).
